Install

Install Pcapy

Pcapy has two parts: an app on your phone that captures, and a plugin that lets Wireshark on your computer receive the capture. Set up both once, then connecting takes a few seconds.

What you need

  • Wireshark 4.x on your computer (developed with 4.6). Download it from wireshark.org.
  • Python 3 on your computer. macOS and most Linux systems already have it. On Windows, install it from python.org.
  • An Android 7+ phone or an iPhone with iOS 15+.
  • The phone and the computer on the same network.

1. Install the phone app

{{> stores}}

When you first tap Start, the system asks permission to set up a VPN. Pcapy uses it only to see and forward the traffic of your own device; see the privacy policy.

2. Install the Wireshark plugin

Download the plugin and unzip it. It contains an installer for each system, the capture interface, and a Wireshark profile that adds an App column.

Download the plugin (.zip)

Integrity check: the SHA-256 of the file is in pcapy-wireshark-plugin.zip.sha256.

macOS and Linux

$ unzip pcapy-wireshark-plugin.zip
$ cd pcapy-wireshark-plugin
$ sh install.sh

The installer asks Wireshark where its plugin folders are, so it also works with unusual setups. It picks the right script for your system (install-macos.sh or install-linux.sh).

Windows

Unzip the file, then double-click install.bat. Or, in PowerShell, from the unzipped folder:

powershell -ExecutionPolicy Bypass -File install.ps1

After installing, quit Wireshark completely and open it again so it loads the plugin.

The plugin is developed and tested on macOS. The Linux and Windows installers follow the same logic but have had less testing. If one misbehaves, the troubleshooting section below shows how to place the files by hand.

Useful options for the installers: --uninstall to remove the plugin, --help to list the rest (-Uninstall on Windows).

3. Connect

  1. On the phone: open Pcapy, set a password of at least 8 characters (the dice button makes a strong random one), choose the apps to capture (Android), and tap Start. The app shows the phone's IP address and the port (19000 by default).
  2. In Wireshark: in the list of capture interfaces, find Pcapy: phone and click the gear icon next to it. Enter the phone's IP address, the port and your password, then save.
  3. Double-click Pcapy: phone to start capturing. Packets appear as your apps use the network.
  4. To see which app sent each packet, choose the Pcapy profile (bottom-right corner of Wireshark). You can also filter with pcapy.app and pcapy.uid.
pcapy.app == "com.example.app"

Troubleshooting

The "Pcapy: phone" interface does not appear in Wireshark
  • Quit Wireshark completely (not just the window) and start it again.
  • Check that Python 3 works: python3 --version (macOS/Linux) or py -3 --version (Windows).
  • Open Help → About Wireshark → Folders. The installer puts pcapy_extcap.py in the Personal Extcap path (on Windows, pcapy_extcap.bat plus a pcapy folder) and pcapy.lua in Personal Lua Plugins. If they are missing, copy them there by hand from the unzipped plugin. On macOS and Linux the extcap file must be executable (chmod +x).
"Cannot connect" or a timeout
  • Make sure the capture is running on the phone (the app shows LIVE).
  • Phone and computer must be on the same network. Guest Wi-Fi networks often block devices from talking to each other.
  • Check the IP address and port against what the app shows. A computer firewall or a VPN on the computer can also get in the way.
"Authentication failed: wrong password"

The password in Wireshark must match the one in the app exactly. The app shows it when you tap the eye icon. Passwords are case-sensitive.

"The phone is refusing connections from this computer"

After a wrong password the phone makes the computer wait: 2 seconds, doubling with every further failure up to 60 seconds. This protects the stream against guessing. Wait for the number of seconds shown, then try again with the right password.

The App column is empty, or filters show nothing
  • Choose the Pcapy profile in the bottom-right corner of Wireshark, or right-click the App field in a packet's details and choose Apply as Column.
  • App names need Android 10 or newer. On iPhone, Apple does not reveal which app a connection belongs to, so the column stays empty.
I do not see DNS lookups

Turn on Show DNS lookups in the app before you start. It makes the system fall back to plain DNS so the queries are readable. If your phone is set to a strict private DNS, turn the option off, otherwise name resolution fails.

Why can't I read the contents of web pages?

HTTPS is encrypted end to end and Pcapy does not decrypt it. You can see the hosts, timing and sizes, not the contents.

Update or uninstall

To update, download the newest plugin zip and run the installer again; it replaces the old files and never overwrites your Pcapy profile. To remove the plugin:

$ sh install.sh --uninstall

On Windows, run install.bat -Uninstall. Your Wireshark profile is kept; delete it in Edit → Configuration Profiles if you want it gone.
